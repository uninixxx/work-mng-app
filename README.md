# 給与明細

自分専用の給与明細保管・集計アプリのソースコードです。アプリ本体はGoogle Apps Script上で動き、給与データはGoogleスプレッドシート、写真はGoogle Driveに保存します。

## GitHub Pagesについて

`docs/` はアプリを開くための起動ページです。GitHub Pages上で給与の入力・保存・写真読み取りを実行する構成ではありません。

Googleアカウントの本人承認とアプリURLの設定がまだ必要です。現在の起動ページは設定待ちを表示し、入力・保存できる画面としては公開しません。

GitHub Pagesの公開元は `main` ブランチの `/docs` を指定します。ルートや `dist/` を公開元には指定しないでください。起動ページは一般に公開されるため、給与データや写真、秘密情報をこのリポジトリへ追加しないでください。

## Googleへの配置

Node.js 20以降で、追加パッケージを入れずに `npm run build` を実行します。

1. 本人のGoogleアカウントでApps Scriptプロジェクトを作成します。
2. 生成された `dist/Code.gs` と `dist/Index.html` をそれぞれスクリプトとHTMLファイルへ配置します。
3. `dist/appsscript.json` をマニフェストに設定します。Drive・Sheets・Docsの高度なサービスを使用します。
4. ウェブアプリとして、自分のアカウントで実行し、アクセスできるユーザーを「自分のみ」にして配置します。
5. 本人が権限の内容を確認します。権限は `drive.file` と、写真取得に使う `script.external_request` です。通信先はGoogle Driveの固定取得先に限定します。
6. Googleから発行された正式な `/exec` URLを、起動ページのリンクに設定します。

GitHubへの配置だけでGoogleの本人承認を省略することはできません。承認と動作確認が済むまで、本番利用できる状態とは扱いません。

## 保存と費用

給与データと写真はGoogleアカウントの無料容量・利用上限の範囲で保存します。無料で無制限の永久保存を保証するものではありません。元画像は端末で圧縮し、保存済みの写真は必要なときだけ取得します。明細写真、利用者の実データ、アクセストークン、秘密鍵、ローカルの下書きはリポジトリに含みません。
